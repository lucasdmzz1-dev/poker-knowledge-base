# 1. Guideline

Fonte principal para construção das regras do módulo.

- conceito do XR Deep;
- construção de valor;
- construção dos bluffs;
- utilização de turns;
- princípios estratégicos.

---

# 2. Videoaulas

Utilizadas para complementar:

- explicação das ideias;
- raciocínio estratégico;
- interpretação das linhas;
- aplicação prática.

---

# 3. Transcrição das Aulas

Utilizada para extrair:

- conceitos detalhados;
- exemplos;
- observações do instrutor;
- justificativas das decisões.

# 4. Solver

Utilizado para validar:

- frequência de XR;
- composição dos combos;
- diferenças entre XR e XC;
- influência dos naipes;
- comportamento por textura.

# 5. Exercícios Práticos

Utilizados para consolidar:

- seleção de combos;
- diferença entre teoria e aplicação;
- identificação de erros;
- criação das regras simplificadas.

---

# 6. Correções e Decisões do Estudo

Foram incorporados:

- ajustes de interpretação;
- correções de leitura do solver;
- regras finais definidas durante a análise.

Principais pontos:

- Deep Stack é baseado em equidade.
- Não XR automático de mãos com showdown.
- Naipes possuem papel fundamental.
- Offs precisam de estrutura para XR.
- Draws fortes entram para extrair.
