# XR Short Stack

## Módulo 06 — XR Short Stack

---

# Contexto

Stack:
20bb

Spot:
XR Short Stack

Relações:

- EP vs BB
- BTN vs BB

Street:
Flop

---

# Objetivo do Módulo

Construir uma estratégia completa de Check Raise em jogo Short Stack.

O módulo aborda:

- Quando realizar XR.
- Quando apenas pagar.
- Construção de ranges de valor.
- Construção de ranges de bluff.
- Mãos que devem permanecer no call.
- Diferença entre boards secos e dinâmicos.
- Quando utilizar XR pequeno.
- Quando utilizar XR shove.

---

# Filosofia Central

Short Stack é realização de equity.

A principal pergunta antes de realizar um XR é:

"Essa mão quer realizar equity?"

Se sim:

A tendência é CALL.

Não devemos transformar mãos que possuem valor em continuar jogando em XR/F.

---

# Estrutura do XR

O range de XR é polar.

Possui:

## Valor

Mãos que:

- Querem jogar por stack.
- Conseguem continuar contra ação.

---

## Bluff

Mãos que:

- Não possuem valor suficiente para call.
- Possuem blockers.
- Aceitam abandonar.

---

# Conceito Principal

XR Short Stack não busca apenas aumentar agressão.

Ele busca:

- Proteger equity quando necessário.
- Extrair valor quando possível.
- Manter mãos de realização no call.

---

# Regras Gerais

- Não fazer XR/F com mãos que queremos realizar.
- SPR baixo não significa shove automático.
- Board dinâmico favorece proteção.
- Board seco favorece extração.

---

# Resultado Esperado

Ao finalizar o módulo o jogador deve entender:

- Quais mãos são XR.
- Quais mãos são call.
- Quais mãos são bluff.
- Quando proteger.
- Quando extrair.
