# BET CHECK BET

## Objetivo do módulo

Dominar a estratégia de aposta no river após a linha:

BET FLOP → CHECK TURN → BET RIVER

O foco principal é entender:

- ranges capados;
- construção de value bet;
- seleção de bluffs;
- classificação dos rivers;
- escolha de sizes.

---

# Conceito central

A estratégia de Bet Check Bet existe principalmente porque ambos os ranges chegam ao river com limitações.

O agressor:

BET FLOP → CHECK TURN

perde parte das mãos fortes que continuariam apostando turn.

O defensor:

CHECK CALL FLOP → CHECK TURN → CHECK RIVER

também possui range capado porque mãos fortes deveriam apostar antes.

A estratégia explora esses ranges capados.

---

# Princípio absoluto

Antes de apostar:

1. Classificar o river.
2. Identificar o range que queremos atacar.
3. Definir se a mão é valor ou bluff.
4. Escolher o size correto.
