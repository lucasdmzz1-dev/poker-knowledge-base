# 08-REFERENCIAS.md

# 3BET POT — REFERÊNCIAS


# OBJETIVO

Registrar todas as fontes utilizadas para construção e consolidação do módulo 3BET POT.


Este arquivo garante rastreabilidade do conhecimento desenvolvido.


---

# FONTES PRINCIPAIS


# 01 — GUIDELINE


Fonte principal de estratégia.


Utilizado para definir:


- Regras gerais;
- Sizes;
- Splits;
- Estrutura das árvores;
- Estratégias base.


---

# 02 — VIDEOAULAS


Material utilizado para:


- Entendimento conceitual;
- Explicação das linhas estratégicas;
- Exemplos práticos;
- Raciocínio do instrutor.


---

# 03 — TRANSCRIÇÕES DAS AULAS


Utilizadas para:


- Preservar explicações detalhadas;
- Registrar exemplos;
- Identificar princípios estratégicos;
- Capturar observações importantes.


---

# 04 — SOLVER


Utilizado para:


- Validar estratégias;
- Observar frequências;
- Identificar misturas;
- Confirmar exceções.


O solver deve ser utilizado como ferramenta de validação, não substituindo o guideline.


---

# 05 — EXERCÍCIOS


Utilizados para:


- Fixação do conteúdo;
- Teste de tomada de decisão;
- Identificação de erros;
- Consolidação das regras.


---

# 06 — CORREÇÕES DO INSTRUTOR


Utilizadas para:


- Ajustar interpretações;
- Corrigir aplicações erradas;
- Consolidar decisões finais.


---

# HIERARQUIA DAS FONTES


Em caso de conflito (ordem geral do KB, `theory/CLAUDE.md`, padronizada em 28/10/2026):


1. Esclarecimentos do autor do KB

2. Correções do instrutor

3. Solver

4. Videoaulas e transcrições

5. Guideline

6. Exercícios


Até 28/10/2026 este módulo usava a ordem invertida (Guideline primeiro e Correções por último).


Caso exista divergência entre fontes, registrar em:


`06-Pendencias.md`


e após decisão final:


`09-Decisoes.md`
