## Objetivo

Registrar apenas conclusões definitivas obtidas durante o estudo.

Uma decisão somente poderá ser registrada quando estiver fundamentada em pelo menos uma das seguintes fontes:

- Guideline
- Videoaulas
- Solver
- Exercícios
- Correções do instrutor

## Estrutura de cada decisão

Cada decisão deverá conter:

- Pergunta
- Conclusão
- Fundamentação
- Fonte(s)
- Status
