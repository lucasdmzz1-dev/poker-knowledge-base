# KB-000 — Poker Knowledge Base Architecture

**Version:** 1.0  
**Status:** Active

---

# Purpose

This document defines the architecture and standards used throughout the Poker Knowledge Base.

Every future module, trainer, leak analysis and application feature must follow these standards.

---

# Philosophy

The Knowledge Base is the single source of truth for the project.

No poker concept should exist only inside conversations.

Every validated concept must eventually become part of the Knowledge Base.

# Knowledge Levels

## Level 1 — Consolidated

Validated through:

- Guideline
- Video lessons
- Practical examples
- Instructor confirmation (when necessary)

Can be used inside the App.

---

## Level 2 — Operational Simplification

Human simplifications used to improve practical play.

Clearly identified.

---

## Level 3 — Hypothesis

Logical conclusions not yet validated.

Cannot be used as official theory.

---

## Level 4 — Pending Validation

Questions waiting for:

- Instructor
- Solver
- Further study

---

# Module Standard

Every poker module must contain:

- Scope
- Philosophy
- Decision Tree
- Board Classification
- Value Hands
- Bluff Hands
- Calls
- Bet Sizes
- Exceptions
- Common Mistakes
- Exercises
- Pending Questions
- Changelog

---

# Versioning

Every module has:

Version

Status

Changelog

No information is deleted.

Only updated.

---

# Goal

Build the most organized poker study system possible.

The Knowledge Base is the foundation for:

- Theory
- Trainers
- Leak Finder
- Hand Analysis
- Future Poker Application
