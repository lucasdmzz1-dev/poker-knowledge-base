# Flashcards

Um deck por módulo, gerado a partir das Regras Consolidadas (e do Guideline quando o módulo tem poucas regras). Para revisar, use o plugin **Spaced Repetition** (instruções no [[00-Home|Home]]).

Cada card termina com a origem (Regra N ou seção). Se um card estiver errado ou desatualizado, corrija a regra no módulo e peça para regenerar o deck.
