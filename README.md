# Poker Knowledge Base

> Building a world-class poker study platform.

## Project Vision

The Poker Knowledge Base is the central repository for all strategic poker knowledge used in the future Poker App.

The project combines:

- Theory
- Practical Trainers
- Leak Finder
- Hand Analysis
- Statistics
- Study Plans
- AI-assisted Coaching
